# Reglas de código

- TypeScript estricto sin `any`.
- Indentación de 4 espacios, comillas dobles, sin punto y coma y sin comentarios.
- El token se guarda en un solo lugar: `AuthContext`.
- No hay llamadas a la API dentro de componentes de página: siempre se usa `services/`.
- La interfaz es mobile-first con Tailwind.
